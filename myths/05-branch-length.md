# «A branch is as long as the distance between its end points»

**We believed:** The length of a cable tray branch is the distance from its first point to its last.

**In fact:** It is the sum of the segments between neighbouring POINTR — for a bent route the chord is shorter.

**Commands:** `FRADIUS` **Verified** — last run 29 Sep 2026

**What we believed.** Length = distance between the first and the last point.

**What refuted it.** Applying the same rule to a different task — counting steel for an order. The right answer is the **sum of segment lengths between neighbouring points**. For a straight branch both give the same number, so the mistake never showed: every run so far had straight routes. On a bent route the chord **under-counts** the length.

**Why the mistake was possible.** A rule written for one case looked general because nothing contradicted it.

**The lesson.** Test your notes by applying them to someone else's task. A rule that holds only for the case it was written for shows it at once. (And with bends there is one more subtlety: the radius is measured on the tray **axis**, not on its edge.)
