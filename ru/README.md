Открытых материалов по PML почти нет, а по кабельным трассам и кабельным конструкциям — практически ничего. То, что есть, в основном из разряда «должно работать». bracketPML — наоборот: реестр команд PML для AVEVA E3D 2.1, где каждая команда **запущена в настоящей модели E3D**. У каждой — дата прогона, дословный ответ E3D и ловушки, найденные по дороге.

**194 команды** в реестре: **107 проверено**, 7 с задокументированной ошибкой, 6 только в макросе, 38 по документации и 36 из реального кода ждут прогона. Последний прогон: 23 октября 2026.

## Модули

<a id="modules"></a>
Маленькие законченные приёмы, которые можно перенести в свои макросы. У каждого есть **проба** — короткий макрос, который показывает поведение в *вашем* E3D, под меткой отката.

- [Надёжная выгрузка — файл, которому можно верить](modules/export-safe/README.md) — Выгрузить данные из E3D в текстовый файл через alpha log так, чтобы сломанный или недописанный файл никогда не сошёл за хороший.
- [Текст в PML без потерь](modules/escaping/README.md) — Как записать в атрибут любой текст — с чертами, кавычками, знаком доллара — и два случая, которые не записать никак.
- [Страховка — отменить массовую правку одной командой](modules/guard/README.md) — Команды UNDO в E3D нет, но откат есть. Поставьте метку перед массовой правкой, проверьте — и либо сохраните, либо откатите всё разом.
- [Сортировка — упорядочить дерево модели за наименьшее число перестановок](modules/reorder/README.md) — Отсортировать содержимое зоны по имени командой REORDER, двигая только то, что стоит не на месте, и доказать результат до того, как код попадёт в E3D.

## Ловушки

<a id="gotchas"></a>
Короткие заметки, названные дословным сообщением E3D: ищите по тексту ошибки — найдёте причину.

- [Блок if падает в окне Commands](gotchas/01-paste-runs-line-by-line.md) — `PML: Invalid syntax in the current context`
- [Часть текста пропадает после $](gotchas/02-dollar-eats-text.md) — `(ошибки нет — текст просто короче)`
- [UNDODB говорит, что откатывать нечего](gotchas/03-no-mark-to-undo.md) — `No mark to UNDO to`
- [Команды UNDO нет — но откат есть](gotchas/04-there-is-no-undo.md) — `CP: Syntax error`
- [С командой всё в порядке — дело в значении](gotchas/05-read-the-caret.md) — `CP: Syntax error`
- [RENAME с двумя именами не работает](gotchas/06-rename-two-names.md) — `(2,109) Undefined name`
- [У результата COLLECT нет методов массива](gotchas/07-collect-has-no-size.md) — `Object does not have a member SIZE`
- [Чтение атрибута в переменную падает](gotchas/08-incompatible-types.md) — `Cannot assign variable to result - incompatible types (STRING=REAL)`
- [Длинную строку нельзя ни собрать, ни записать](gotchas/09-string-too-long.md) — `CALCULATOR ERROR: The concatenated text is too long`
- [Файл, прочитанный из PML, превращается в «кракозябры»](gotchas/10-readfile-encoding.md) — `(ошибки нет — «РЎРўРђР РћР•» вместо текста)`
- [POS поставил элемент не туда](gotchas/11-pos-is-from-owner.md) — `(ошибки нет — элемент просто в другом месте)`
- [E3D принимает ящик длиной −100](gotchas/12-e3d-does-not-check-sizes.md) — `(ошибки нет — XLEN -100 принят)`

## Мифы

<a id="myths"></a>
В чём мы были уверены и ошиблись — и **почему** ошибка была возможна. Неверный факт исправляют один раз, а неверный способ рассуждать повторяется.

- [«В мануале сказано, что if работает в командной строке»](myths/01-blocks-in-command-line.md) — Обычная вставка выполняет каждую строку отдельно, и if падает с «PML: Invalid syntax». Блоки работают через Paste as Macro.
- [«В E3D нет отката»](myths/02-no-rollback.md) — Откат — это MARKDB / UNDODB. Один UNDODB возвращает всё, что сделано под меткой, — до SAVEWORK.
- [«CABLAY не работает»](myths/03-cablay-disputed.md) — «Крышечки» стояли на значении. CABLAY |CEN| работает; текстовым значениям нужны черты.
- [«Q MEM ATT печатает атрибуты потомков»](myths/04-q-mem-att.md) — Q MEM ATT — это Q MEM плюс Q ATT ТЕКУЩЕГО элемента. Атрибутов потомков там нет.
- [«Длина ветки — расстояние между её концами»](myths/05-branch-length.md) — Это сумма отрезков между соседними POINTR — у изогнутой трассы хорда короче.
- [«Команды GOTO нет»](myths/06-no-goto.md) — GOTO есть, но он идёт по ссылочному атрибуту (GOTO OWNER, GOTO PARENT…), а не по имени.
- [«PMLLIB не задан»](myths/07-pmllib-not-set.md) — Q EVAR |PMLLIB| внутри E3D печатает около десятка путей. (Обычному пользователю писать в них нельзя — так что вывод подтвердился, но случайно.)
- [«Геометрия лотка — в точках маршрута»](myths/08-geometry-in-points.md) — Числа сходились — но манипулятор правки стоит на POS ветки. При POS в нуле все манипуляторы оказывались на первом лотке.
- [«RENAME /СТАРОЕ /НОВОЕ переименовывает элемент»](myths/09-rename-two-names.md) — Формы с двумя аргументами нет — «(2,109) Undefined name». Встаньте на элемент и RENAME /НОВОЕ (или NAME /НОВОЕ).

## Как пользоваться

- **Ищите** по всей библиотеке на [bracketbim.com/pml/ru](https://bracketbim.com/pml/ru/): по команде, по тексту ошибки, по статусу.
- **Копируйте** модуль в свою папку макросов. Файлы `.pmlmac` — обычный текст; вставляйте их правым кликом → *Paste as Macro*.
- **Проверяйте** всё на своей установке пробой. Если ваш E3D отвечает иначе, [напишите нам](../CONTRIBUTING.md) — ваша версия попадёт в реестр.

Код модулей и комментарии в нём — на английском: так он одинаков в обеих версиях и не зависит от кодировки E3D.
