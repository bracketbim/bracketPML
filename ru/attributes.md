# Атрибуты

Штатные атрибуты элементов AVEVA E3D 2.1, которые мы знаем: состав, владельцы и потомки — по Data Model Reference Manual 2.1 (номер страницы у каждого типа), описания, статусы и пояснения — наши. Пользовательские атрибуты проекта (`:ИМЯ`) сюда не входят.

| Статус | Что значит |
|---|---|
| **Команда проверена** | Команда, которая его пишет или читает, запускалась в E3D — хотя бы на одном типе элемента; на каком — сказано в строке реестра. |
| **Есть в модели** | Q ATT напечатал его на реальной модели; сами ещё не писали. |
| **По мануалу** | Есть в Data Model Reference Manual 2.1; в наших выгрузках не встречался. |
