# Блок if падает в окне Commands

> Обычная вставка выполняет каждую строку отдельной командой — блоки не собираются, а вставка останавливается на первой ошибке.

**E3D пишет:** `PML: Invalid syntax in the current context`

**Команды:** `IF` **Только макрос** · `DO` **Только макрос** · `HANDLE` **Только макрос** · `PASTE` **Проверено**

## Что вы видите

Вставляете в окно Commands макрос с `if … endif` и получаете `PML: Invalid syntax` на строке `if` — и ещё раз на `endif`. Или длинная вставка останавливается на середине, и строки после ошибки так и не выполняются.

## Почему

В руководстве Common Functionality сказано дословно: обычная вставка «executes each line of the copied text as a separate command as if they had been typed» — выполняет каждую строку как отдельную команду, будто её набрали руками. Строка `if` сама по себе — незаконченная конструкция, поэтому падает. А вставка ведёт себя как временный макрос: на первой ошибке **остальное не выполняется** — хвост придётся ввести заново.

## Как правильно

- Однострочные команды — вставлять как обычно.
- Всё, где есть `if`, `do`, `handle`, — **правый клик → Paste as Macro**. Вставка пишется во временный файл и выполняется как макрос; блоки там работают.
- После остановившейся вставки посмотрите, где она остановилась, прежде чем вставлять снова, — первая часть уже выполнена.

## Проверьте сами

Вставьте это обоими способами. Обычная вставка падает на `if`; Paste as Macro печатает `big`.

```
!x = 7
if (!x GT 5) then
  $P big
endif
```
