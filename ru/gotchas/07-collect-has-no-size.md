# У результата COLLECT нет методов массива

> VAR !x COLLECT … даёт список, по которому можно пройти циклом, но вызвать .Size() нельзя. Считайте внутри цикла.

**E3D пишет:** `Object does not have a member SIZE`

**Команды:** `VAR` **Проверено** — последний прогон 23 сентября 2026 · `COLLECT` **Ошибка** — последний прогон 22 сентября 2026 · `DO` **Только макрос**

## Что вы видите

```
VAR !!x COLLECT ALL CWBRAN FOR CE
$P $!!x.Size()
Object does not have a member SIZE
```

В макросе то же самое — дело не в способе вставки.

## Почему

`COLLECT` — не самостоятельная команда (`COLLECT $Q` — синтаксическая ошибка); он существует только как хвост `VAR`. Результат — не объект `ARRAY`, поэтому методов массива у него нет. Но `do … values` проходит по нему без проблем, и переход `$!e` внутри цикла ведёт к каждому элементу.

## Как правильно

Пройдите циклом и посчитайте сами:

```
VAR !items COLLECT ALL CWBRAN FOR CE
!n = 0
do !e values !items
  !n = !n + 1
enddo
$P branches: $!n
```

Ещё две вещи, которые стоит знать:

- `FOR <элемент>` берёт **всё** под ним, включая вложенные элементы.
- Условие может проверять атрибут напрямую: `WITH (UNSET(DESC))` найдёт ветки без описания. Неверное условие даёт пустой список, а не ошибку, — сверяйте количество с ожидаемым.
