# Чтение атрибута в переменную падает

> !x = MAXLAY падает, если в !x уже лежит строка. VAR !x MAXLAY работает, что бы ни было в переменной.

**E3D пишет:** `Cannot assign variable to result - incompatible types (STRING=REAL)`

**Команды:** `VAR` **Проверено** — последний прогон 23 сентября 2026

## Что вы видите

Макрос читает несколько атрибутов в одну и ту же переменную. Первый читается, а потом:

```
Cannot assign variable to result - incompatible types (STRING=REAL)
```

## Почему

Присваивание `!x = MAXLAY` сохраняет тип переменной. Если в `!x` уже строка, а атрибут числовой, типы конфликтуют. Работает это только в новой переменной.

## Как правильно

Читайте атрибуты через `VAR`: он не зависит от того, что было в переменной раньше, и работает и в командной строке (с глобальной переменной `!!`).

```
!x = 'some text'
VAR !x MAXLAY
q var !x
```

На ветке кабельной трассы это напечатает её значение MaxLay — без конфликта типов.
