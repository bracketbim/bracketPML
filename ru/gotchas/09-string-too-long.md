# Длинную строку нельзя ни собрать, ни записать

> Строка PML ограничена примерно 1000 символами, а WriteFile отказывается писать строку где-то между 800 и 1200 байт. Держите каждую строку выгрузки короче 800 байт.

**E3D пишет:** `CALCULATOR ERROR: The concatenated text is too long`

**Команды:** `WRITEFILE` **Проверено**

## Что вы видите

Макрос собирает строку CSV, склеивая атрибуты, и пишет её через `WriteFile`. Большинство строк в порядке, одна падает с `CALCULATOR ERROR: The concatenated text is too long`. Или `WriteFile` падает, и файл остаётся пустым — только три байта BOM.

## Почему

Два разных предела:

- **Сборка строки:** строка в 1000 символов записалась; приклеить к ней ещё — не вышло. Строка PML вмещает примерно 1000–1100 символов.
- **Запись строки:** 400 нелатинских букв (800 байт в UTF-8) записались; 600 букв (1200 байт) — нет, хотя сама строка собралась. У записи в файл свой предел, и считается он в **байтах**.

Нелатинский текст в UTF-8 занимает два байта на букву, поэтому «короткая» кириллическая строка упирается в предел вдвое быстрее.

## Как правильно

- Держите каждую строку выгрузки короче **800 байт**.
- Широкие записи разбивайте: по строке на группу атрибутов или по атрибуту на строку с `=ref` элемента впереди.
- Для выгрузки лучше `alpha log` + `$P` — см. [надёжную выгрузку](../modules/export-safe/README.md).
