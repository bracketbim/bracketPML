# Текст в PML без потерь

> Как записать в атрибут любой текст — с чертами, кавычками, знаком доллара — и два случая, которые не записать никак.

**Команды:** `DESC` **Проверено** · `CABLAY` **Проверено** · `NAME` **Проверено** · `$M` **Проверено**

Когда PML генерируется из Excel, Python или веб-страницы, каждое текстовое значение нужно **обернуть**, чтобы E3D прочитал его как текст. Ошибётесь — и E3D сделает одно из двух: остановится с `CP: Syntax error` (это хороший случай) или **молча запишет другой текст**. Ради второго случая этот модуль и существует.

## Правила

| Ваш текст | Как писать | Что сохранит E3D | Статус |
|---|---|---|---|
| `cable tray 600` | `DESC \|cable tray 600\|` | `cable tray 600` | **Проверено** |
| `cable tray 600` | `DESC 'cable tray 600'` | `cable tray 600` | **Проверено** — одинарные кавычки равны чертам |
| `price $5` | `DESC \|price $$5\|` | `price $5` | **Проверено** — каждый `$` удваивается |
| `price $5` в **макросе**, без удвоения | `DESC \|a$1b\|` | `ab` — **`$1` съеден** как аргумент макроса | **Проверено** |
| `3/4" pipe` | `DESC \|3/4" pipe\|` | `3/4" pipe` | **Проверено** — двойная кавычка пишется как есть |
| `CEN` (текстовый атрибут) | `CABLAY \|CEN\|` | `CEN` | **Проверено** — `CABLAY CEN` без черт — синтаксическая ошибка |
| `600` (числовой атрибут) | `VWIDTH 600` или `VWIDTH 600mm` | `600mm` | **Проверено** — у чисел **черт нет**: `VWIDTH \|600\|` — синтаксическая ошибка |

### Два текста, которые не записать

- **Перевод строки.** Команда PML — одна строка; остаток текста выполнится как отдельная команда. Заменяйте переводы строк до записи.
- **Вертикальная черта *и* апостроф в одном тексте.** Черты — это обёртка, поэтому текст с чертой берут в одинарные кавычки — и тогда апострофу уже нечем обернуться. Замените один из двух символов.

И консоль, и помощники ниже такой текст **отклоняют**, а не записывают вместо него что-то другое.

## Почему важен знак доллара

`$` в PML — управляющий символ: `$1…$9` — аргументы макроса, `$!x` подставляет переменную. В макросе `DESC |a$1b|` запишет `ab` — без ошибки, просто текст станет короче. Удвоение помогает и при обычной вставке, и в Paste as Macro: `$$` превращается в один `$`.

## С именами строже

Имя — одно слово: пробел разрывает команду надвое, а кавычки, черты и `$` недопустимы. Имя должно начинаться с `/` — без него E3D не переходит к элементу, **молча**, и следующий `POS` попадёт в тот элемент, который был текущим.

## Файлы

| Файл | Что это |
|---|---|
| [`pml_text.py`](../../../modules/escaping/pml_text.py) | `pml_text(value)` и `pml_name(value)` для Python — обернуть, удвоить `$`, отклонить то, что не записать. |
| [`pml_text.js`](../../../modules/escaping/pml_text.js) | То же для JavaScript (браузер или Node). |
| [`probe.pmlmac`](../../../modules/escaping/probe.pmlmac) | Проверка правил в **вашем** E3D: пишет тестовые описания под меткой отката и откатывает их. |

```python
from pml_text import pml_text, pml_name
pml_text('price $5')        # -> |price $$5|
pml_text('a|b')             # -> 'a|b'
pml_name('PMLC-CWAY-T1')    # -> /PMLC-CWAY-T1
pml_text('line 1\nline 2')  # raises ValueError: line break
```

## Проверьте сами

`probe.pmlmac` работает с **одним элементом, на котором вы стоите** (EQUI, SUBE, ветка — что угодно с DESC). Проба ставит метку отката, пишет несколько описаний, печатает, что сохранил E3D, и откатывает всё через `UNDODB`. Запускайте на тестовом проекте; в модели ничего не останется, если между делом не сделать `SAVEWORK`.

Одна строка пробы помечена как **нами ещё не проверенная** — черта внутри одинарных кавычек. Напишите, что выдал ваш E3D, и в реестре появится новая строка: [отчёт о проверке](../../../CONTRIBUTING.md).

## Проверено

| Команда | Что делает | Статус |
|---|---|---|
| `$M C:\Temp\file.pmlmac` | То же, но командой | Проверено |
| `CABLAY \|CEN\|` | Раскладка кабелей | Проверено |
| `CABLAY CEN` | Так НЕ работает | Ошибка |
| `DESC \|текст с пробелами\|` | Записать описание | Проверено |
| `NAME /НОВОЕ` | Переименовать ТЕКУЩИЙ элемент | Проверено |
| `$M C:\Temp\t.mac арг1 арг2` | Запустить макрос из Command Line с аргументами | Проверено |
