# Надёжная выгрузка — файл, которому можно верить

> Выгрузить данные из E3D в текстовый файл через alpha log так, чтобы сломанный или недописанный файл никогда не сошёл за хороший.

**Команды:** `ALPHA LOG` **Проверено** · `HANDLE` **Только макрос** · `VAR` **Проверено** · `$P` **Проверено** · `DO` **Только макрос**

Достать данные **из** E3D — первый шаг почти любой автоматизации: список трасс для подсчёта метража, оборудование для тегирования, дерево для сортировки. Обычный способ — `alpha log`: всё, что печатает окно Commands, уходит в файл. Это работает, но ломается тремя тихими способами. Каждый стоил нам настоящей проверки в E3D.

## Три тихих сбоя

| # | Что происходит | Чем опасно |
|---|---|---|
| 1 | **Лог остался открытым.** Макрос остановился на ошибке посередине, и `alpha log END` так и не выполнился. Следующий макрос не может открыть свой лог — E3D всё ещё пишет в старый. | Вы видите ошибку, которая не имеет отношения к новому макросу. Пока не наберёте `alpha log END` руками, ничего не работает. |
| 2 | **Файл недописан.** Макрос остановился на середине, но файл есть и выглядит нормально. | Скрипт читает его и обрабатывает 40 трасс вместо 120 — и молчит. |
| 3 | **Зоны не существует.** В одном имени из списка опечатка (`/env-2` вместо `/env_2`). Paste as Macro на нём останавливается. | Всё после плохой зоны теряется, а следом приходят сбои 1 и 2. |

## Приём

Пять идей, все проверены в E3D 2.1:

1. **Сначала закрыть чужой открытый лог.** `alpha log END` под `handle any`: если лог не открыт, ошибка перехватывается и макрос идёт дальше.
2. **Считать то, что пишешь.** Счётчик `!n` растёт с каждой строкой данных.
3. **Закончить счётом.** Последняя строка — `#BPML END <n>`. Читатель проверяет, что она есть **и** что число совпадает с прочитанными строками. Нет последней строки — файл сломан. Число не то — файл сломан.
4. **Охранять каждую зону.** Переход в зону — под `handle any`; если её нет, пишется `#BPML NOAREA <имя>` и зона пропускается — остальное всё равно выгружается.
5. **Закрыть лог в конце** командой `alpha log END`.

```
alpha log END                              $* close a log left open by a stopped macro
handle any                                 $* … no log open — the error is caught here
endhandle
!n = 0
alpha log /C:\Temp\bpml-export.txt OVERWRITE
$P #BPML BEGIN
…  $P #ITEM … ;  !n = !n + 1  for every item …
$P #BPML END $!n                           $* the reader checks this number
alpha log END
```

`handle any` ставится **сразу после** строки, которую охраняет, а не перед ней — так E3D привязывает обработчик.

## Запуск

1. В E3D встаньте на зону (или площадку) с кабельными трассами.
2. Откройте макрос, скопируйте всё, правый клик в окне Commands → **Paste as Macro**.
3. Последняя строка в окне скажет, куда лёг файл и сколько в нём строк.
4. `python read_export.py C:\Temp\bpml-export.txt` — выведет элементы или точно скажет, почему файлу верить нельзя.

## Полезно знать

- Файл — **UTF-8 с BOM**. В Python читайте его с `utf-8-sig`, иначе первая строка начнётся с трёх лишних байт.
- `alpha log` пишет **ответы и ошибки**, а не сами команды.
- `COLLECT … FOR <элемент>` берёт **всё** под элементом, включая вложенное. Если нужны только прямые потомки, проверяйте владельца каждого элемента.
- Строка PML — не длиннее примерно 1000 символов; держите одну записываемую строку заметно короче.

## Проверено

| Команда | Что делает | Статус |
|---|---|---|
| `alpha log /C:\Temp\log.txt OVERWRITE` | Писать всё, что печатает окно, в файл | Проверено |
| `alpha log END` | Закончить запись в файл | Проверено |
| `VAR !!x ACTTYPE` | Тип элемента проекта (:EXTZONE) | Проверено |
| `VAR !!x NAME` | Прочитать атрибут текущего элемента в переменную | Проверено |
| `$P $!!x` | Напечатать значение | Проверено |
| `VAR !!eq COLLECT ALL EQUI WITH ( TYPE EQ 'EQUI' ) FOR CE` | Собрать элементы с фильтром | Проверено |
| `do … enddo` | Цикл | Только макрос |
| `VAR !!x OWNER` | Владелец элемента в переменную — потом $!!x переходит к нему | Проверено |
| `VAR !x COLLECT ALL CWBRAN WITH (UNSET(DESC)) FOR /PMLC` | Собрать с условием на атрибут | Проверено |
| `VAR !s COLLECT ALL SITE FOR WORLD` | Собрать по всей базе | Проверено |
| `do !i from 1 to 10` | Цикл по счётчику | Только макрос |
| `do !i from 1 to 10 by 2` | Цикл с шагом | Проверено |
| `do !elem values !array` | Перебор значений массива | Только макрос |
| `do !i indices !array` | Перебор индексов | Только макрос |
| `do while ( !flag )` | Цикл по условию — так НЕ работает | Ошибка |
| `handle any … endhandle` | Перехват любой ошибки | Только макрос |
| `handle (41,64)` | Перехват конкретной ошибки по номеру | По документации |
