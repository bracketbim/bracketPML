# «В мануале сказано, что if работает в командной строке»

**Мы думали:** if, do и handle работают, если их набрать или вставить в окно Commands, — в мануале сказано, что ввод с клавиатуры и из макроса обрабатывается одинаково.

**На деле:** Обычная вставка выполняет каждую строку отдельно, и if падает с «PML: Invalid syntax». Блоки работают через Paste as Macro.

**Команды:** `IF` **Только макрос** · `DO` **Только макрос** · `HANDLE` **Только макрос**

**Что мы думали.** Сначала — догадка, что блоки в командной строке падают. Потом — цитата из руководства по PML (Software Customisation Guide 2.1, 8.08.2): «The program does not discriminate between input from the GUI, the keyboard, or a macro file» (программа не различает ввод из интерфейса, с клавиатуры или из файла макроса). И мы написали, что ошибались.

**Что показал прогон.** `if (!!t GT 1) then` → `PML: Invalid syntax in the current context`. То же с `do … enddo` и `endhandle`. Первая догадка была верной, а «поправка» по мануалу — нет.

**Почему ошибка была возможна.** Мануал описывает язык PML целиком. Поле командной строки принимает не всё. Цитата из мануала — утверждение о продукте, а не о вашей установке.

**Урок.** Доверять в таком порядке: прогон > `$Q` на живой машине > документация > реальный код с GitHub > рассуждение.
