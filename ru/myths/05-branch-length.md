# «Длина ветки — расстояние между её концами»

**Мы думали:** Длина ветки кабельной трассы — расстояние от первой точки до последней.

**На деле:** Это сумма отрезков между соседними POINTR — у изогнутой трассы хорда короче.

**Команды:** `FRADIUS` **Проверено** — последний прогон 29 сентября 2026

**Что мы думали.** Длина = расстояние между первой и последней точкой.

**Что это опровергло.** То же правило, применённое к другой задаче, — подсчёту металла для заказа. Правильный ответ — **сумма длин отрезков между соседними точками**. Для прямой ветки оба способа дают одно число, поэтому ошибка не проявлялась: во всех прогонах до того трассы были прямыми. На изогнутой трассе хорда **занижает** длину.

**Почему ошибка была возможна.** Правило, написанное для одного случая, выглядело общим, потому что ему ничто не противоречило.

**Урок.** Проверяйте свои записи, применяя их к чужой задаче. Правило, которое верно только для своего случая, сразу себя выдаст. (А с изгибами есть ещё тонкость: радиус меряется по **оси** лотка, а не по краю.)
