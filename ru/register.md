## Само окно Commands — как оно исполняет вставленное

Common Functionality User Guide 2.1, раздел Command Window. Окно открывается на вкладке Home, группа Windows; по умолчанию скрыто. Это описание объясняет ГЛАВНУЮ особенность: обычная вставка выполняет каждую строку отдельно, поэтому блок из нескольких строк не собирается. ## Язык PML — работает в файле макроса, не в Command Line

E3D 2.1 понимает PML2 с полной обратной совместимостью с PML1: интерпретатор один, синтаксис обеих версий работает и в реальных макросах смешивается. Всё, что занимает больше одной строки, обычной вставкой не выполнится — каждая строка идёт как отдельная команда, и прогон 26.08 это показал: ошибка выпала отдельно на if и отдельно на endif. НО документация даёт выход: правый клик → Paste as Macro складывает вставленное во временный файл и выполняет как макрос, и там блоки собираются. То есть логику можно выполнять прямо из окна Commands — просто другим пунктом меню.
