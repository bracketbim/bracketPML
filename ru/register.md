# Реестр

Все известные нам команды PML — со статусом. Файл **собирается** из источника правды при каждой сборке — правки присылайте [отчётом о проверке](../CONTRIBUTING.md).

| Статус | Что значит | Строк |
|---|---|---|
| **Проверено** | Проверено в E3D 2.1, результат сверен. | 144 |
| **Ошибка** | Проверено в E3D 2.1 и дало ошибку — не использовать; в строке сказано, чем заменить. | 11 |
| **Только макрос** | Работает в файле макроса или через Paste as Macro, не построчно. | 16 |
| **По документации** | Есть в документации AVEVA или в грамматике $Q; в E3D ещё не проверено. | 30 |
| **Встречено в коде** | Встречается в реальном PML-коде; в E3D ещё не проверено. | 8 |

## Само окно Commands — как оно исполняет вставленное

Common Functionality User Guide 2.1, раздел Command Window. Окно открывается на вкладке Home → Windows и по умолчанию скрыто. Главное: обычная вставка выполняет каждую строку отдельной командой, поэтому многострочный блок не собирается. Во втором пункте меню правого клика — решение.

| Команда | Что делает | Статус | Пояснение |
|---|---|---|---|
| <a id="right-click-paste"></a>`правый клик → Paste` | Обычная вставка | Проверено | Дословно: «executes each line of the copied text as a separate command as if they had been typed». Каждая строка — отдельная команда, поэтому if/do/handle не проходят (Invalid syntax). Первая ошибка останавливает остаток вставки — пробы, которые ждут ошибку, кладите в макрос. |
| <a id="right-click-paste-as-macro"></a>`правый клик → Paste as Macro` | Вставить как макрос | Проверено | Дословно: «first creates a temporary file containing the copied macro commands and executes this as a macro». Вставленное идёт временным макросом: if, do и handle работают. |
| <a id="drag-a-mac-file-from-explorer"></a>`перетащить .mac из проводника` | Выполнить файл макроса | По документации | «Macro files can also be dragged into the command window». |
| <a id="m-c-temp-file-pmlmac"></a>`$M C:\Temp\file.pmlmac` | То же, но командой | Проверено | Аргументы $1…$9 работают. |
| <a id="alpha-log-c-temp-log-txt-overwrite"></a>`alpha log /C:\Temp\log.txt OVERWRITE` | Писать всё, что печатает окно, в файл | Проверено | Длинные выводы Q MEM и Q ATT ложатся целиком, без обрезки окна. Файл — UTF-8 с BOM. Остановить — alpha log END. |
| <a id="alpha-log-end"></a>`alpha log END` | Закончить запись в файл | Проверено |  |
| <a id="double-click-a-history-line"></a>`двойной клик по строке истории` | Вернуть команду в поле ввода | По документации | Стрелки вверх и вниз листают историю. |
| <a id="right-click-clear"></a>`правый клик → Clear` | Очистить окно | По документации | Окно держит примерно последние 1000 строк вывода. |
| <a id="q-evar-pmllib"></a>`Q EVAR \|PMLLIB\|` | Узнать путь к библиотеке PML изнутри E3D | Проверено | Печатает десяток путей. Это переменная E3D, а не Windows — echo %PMLLIB% в cmd её не видит. Но в эти папки обычному пользователю писать нельзя: свои функции и формы через PMLLIB недоступны. |
| <a id="pml-rehash-all"></a>`PML REHASH ALL` | Перечитать библиотеку после правки .pmlfnc | Проверено | В макросе выполнилась без ошибки. |
| <a id="pml-index"></a>`PML INDEX` | Индекс библиотеки | По документации |  |
| <a id="pml-trace-on"></a>`PML TRACE ON` | Трассировка выполнения PML | Проверено | PML TRACE ON и OFF выполнились без ошибки. |

## Куда встать — навигация

Почти любая команда работает с текущим элементом (CE). Сначала встают на него, потом действуют.

| Команда | Что делает | Статус | Пояснение |
|---|---|---|---|
| <a id="pmlc-cway-t1"></a>`/PMLC-CWAY-T1` | Перейти к элементу по имени | Проверено | Главный способ: просто имя отдельной строкой. |
| <a id="rpath-1"></a>`RPATH 1` | Войти в член текущего элемента по типу и номеру | Проверено | Внутри ветки: RPATH 1, затем POINTR 2. |
| <a id="pointr-2"></a>`POINTR 2` | Вторая точка маршрута | Проверено | Работает после захода в RPATH. |
| <a id="equipment-2-of-extzone-pmlc"></a>`EQUIPMENT 2 of :EXTZONE /PMLC` | Перейти к безымянному элементу по номеру | Проверено | Номер считает ВСЕХ членов зоны и сдвигается при переносе элементов. |
| <a id="12345678-7844"></a>`=12345678/7844` | Перейти по устойчивой ссылке | Проверено | Работает; Q NAME после него печатает имя. Ссылка не сдвигается при переносе и переименовании — массовые операции только по =ref. |
| <a id="owner"></a>`OWNER` | Подняться к владельцу | Проверено | Из SUBE — в его EQUI. |
| <a id="goto-owner"></a>`GOTO OWNER` | Перейти по ссылочному атрибуту | Проверено | GOTO $Q печатает, что может идти дальше: CFDPROPERTY, LFDPROPERTY, TFDPROPERTY, FRSTWORLD, PARENT, SPLPARENT, CLCONNECTIONS и «any reference attribute». Команда есть, но переходит по ССЫЛКЕ, а не по имени. Из SUBE перешла в его EQUI. |
| <a id="goto-name"></a>`GOTO /ИМЯ` | Так НЕ работает | Ошибка | CP: Syntax error. Имени среди продолжений GOTO нет — поэтому и падает. Переход по имени — просто само имя: /PMLC-CWAY-T1. Переход к метке в макросе — GOLABEL. |

## Язык PML — работает в файле макроса, не в Command Line

E3D 2.1 исполняет PML2 с полной совместимостью с PML1: интерпретатор один, оба синтаксиса работают и смешиваются в реальных макросах. Всё, что длиннее одной строки, обычной вставкой не выполнится — каждая строка уходит отдельной командой (if и endif падают по отдельности). Выход есть в документации: правый клик → Paste as Macro пишет вставку во временный файл и выполняет его как макрос, а там блоки работают. Значит, логику можно запускать прямо из окна Commands — просто другим пунктом меню.

| Команда | Что делает | Статус | Пояснение |
|---|---|---|---|
| <a id="comment"></a>`$* комментарий` | Комментарий в макросе | Проверено | $* и -- — оба комментарии; кириллица после $* в макросе проходит. |
| <a id="if-x-gt-5-then-elseif-else-endif"></a>`if ( !x gt 5 ) then … elseif … else … endif` | Условие, форма PML1 | Только макрос | В макросе if … elseif … else выбрал среднюю ветку. Сравнивать словами: GT LT EQ. |
| <a id="if-x-5-and-n-matchwild-pipe-then"></a>`if ( !x > 5 and !n.Matchwild('PIPE*') ) then` | Условие, форма PML2 | Ошибка | Знак > в условии даёт Meaningless symbol(s) и останавливает макрос. Только слова GT, LT, EQ. |
| <a id="do-i-from-1-to-10"></a>`do !i from 1 to 10` | Цикл по счётчику | Только макрос | В макросе do !i from 1 to 3 напечатал 1, 2, 3. |
| <a id="do-i-from-1-to-10-by-2"></a>`do !i from 1 to 10 by 2` | Цикл с шагом | Проверено | В макросе do !i from 1 to 5 by 2 напечатал 1, 3, 5. |
| <a id="do-elem-values-array"></a>`do !elem values !array` | Перебор значений массива | Только макрос | В макросе по массиву a, b напечатал a, b. |
| <a id="do-i-indices-array"></a>`do !i indices !array` | Перебор индексов | Только макрос | В макросе по массиву из двух дал индексы 1, 2. |
| <a id="do-while-flag"></a>`do while ( !flag )` | Цикл по условию — так НЕ работает | Ошибка | В макросе: CP: Syntax error с указателем на while; макрос встаёт (handle не ловит). Вместо — do без условия с break if ( … ). |
| <a id="break"></a>`break` | Выйти из цикла | Только макрос | Цикл 1…5 с break на 3 напечатал 1, 2. |
| <a id="skip"></a>`skip` | Перейти к следующей итерации | Только макрос | Цикл 1…4 с skip на 2 напечатал 1, 3, 4. |
| <a id="break-if-skip-if"></a>`break if ( … ) / skip if ( … )` | Выход и пропуск по условию | Только макрос | Оба работают в макросе; do с break if заменяет do while. |
| <a id="handle-any-endhandle-2"></a>`handle any … endhandle` | Перехват любой ошибки | Только макрос | Ставить сразу после охраняемой строки. Ошибка перехвачена, макрос идёт дальше. |
| <a id="handle-41-64"></a>`handle (41,64)` | Перехват конкретной ошибки по номеру | По документации | В корпусе кода не встречалась. Проверен другой номер — handle (2,109). |
| <a id="elsehandle-none-elsehandle-any"></a>`elsehandle NONE / elsehandle ANY` | Ветки обработки: без ошибки / любая | Только макрос | Обе ветки работают в макросе. |
| <a id="error-text"></a>`$!!error.text` | Текст пойманной ошибки | Только макрос | Текст перехваченной ошибки. q var !!error показывает PUBLIC_ERROR с TEXT, LINE, COMMAND, CALLSTACK; члена code нет. |
| <a id="return-error-1-could-not-run"></a>`return error 1 'Не удалось выполнить'` | Бросить свою ошибку наверх | Проверено | Текст ошибки виден в окне, макрос останавливается. |
| <a id="m-c-temp-t-mac-arg1-arg2-2"></a>`$M C:\Temp\t.mac арг1 арг2` | Запустить макрос из Command Line | Проверено | Единственный мост между командной строкой и языком: сам вызов работает. |
| <a id="define-function-name"></a>`define function !!имя` | Функция в файле имя.pmlfnc | Проверено | Работает из своей папки PMLLIB, поставленной первой в списке: после pml rehash функция из .pmlfnc выполнилась. |
| <a id="setup-form-name-exit"></a>`setup form !!имя … exit` | Форма с полями и кнопками прямо из макроса | Проверено | Через Paste as Macro форма появилась без PMLLIB, кнопки работают — поле, !!CE.Name, q var, $M файл.mac. define method после exit — Method not found: логику держать в .mac. |
| <a id="endif"></a>`endif` | Конец if (только в макросе) | Только макрос | Обычная вставка — Invalid syntax; через Paste as Macro — работает. |
| <a id="enddo"></a>`enddo` | Конец do (только в макросе) | Только макрос | То же. |
| <a id="endhandle"></a>`endhandle` | Конец handle (только в макросе) | Только макрос | То же. |
| <a id="golabel-label"></a>`golabel /метка` | Переход к метке (и label /метка) | Проверено | Только в макросе; проверено в E3D 2.1. |
| <a id="return"></a>`return` | Выход из файла PML | Проверено | Строки после return не выполнились. |
| <a id="view-v-volume-width-60-height-20"></a>`view .v VOLUME width 60 height 20` | Окно 3D в форме из макроса | Проверено | Показывает всё, что показывает главный 3D-вид. |
| <a id="edgpacket"></a>`EDGPACKET` | Указать точку на ребре щелчком (definePosition) | Проверено | q var печатает точку WRT владельца; пакет живёт до Esc. |
