# Синтаксис команд

Что принимает каждая команда, которую мы запускали. Формы записи и их статусы — из [реестра](register.md); описание аргументов — только по тому, что показали прогоны.

## `NAV` — Перейти к элементу

| Аргумент | Что это |
|---|---|
| `/NAME` | Полное имя с косой чертой впереди. Без неё E3D не переходит — молча. |
| `=REF` | Устойчивая ссылка вида =12345678/7844. Не сдвигается при переносах и переименованиях — для массовой работы только она. |
| `TYPE n` | n-й член этого типа внутри текущего элемента: RPATH 1, затем POINTR 2. |
| `TYPE n OF owner` | n считается среди ВСЕХ членов владельца и сдвигается при переносах. |

Элемент становится текущим (CE).

**Формы**

- `/PMLC-CWAY-T1` — Проверено · Перейти к элементу по имени
- `EQUIPMENT 2 of :EXTZONE /PMLC` — Проверено · Перейти к безымянному элементу по номеру
- `=12345678/7844` — Проверено · Перейти по устойчивой ссылке

## `NEW` — Создать элемент внутри текущего

| Аргумент | Что это |
|---|---|
| `TYPE` | CWAY, CWBRAN, RPATH, POINTR, HATTA, TATTA, EQUI, SUBE, BOX, CYLINDER… Текущий элемент должен быть допустимым владельцем: CWAY — в ZONE, CWBRAN — в CWAY, SUBE — только в EQUI. |
| `/NAME` | Необязательно: имя нового элемента. |
| `$Q` | Вместо создания печатает грамматику команды в вашей сборке: NEW EQUI $Q. |

Новый элемент становится текущим — кроме NEW POINTR: CE остаётся на месте. NEW RPATH точек не создаёт.

**Формы**

- `NEW CWAY /PMLC-CWAY-T1` — Проверено · Создать кабельную трассу внутри зоны
- `NEW CWBRAN /PMLC-CWBRAN-T2/01` — Проверено · Создать ветку внутри трассы
- `NEW RPATH` — Проверено · Создать маршрут
- `NEW POINTR` — Проверено · Добавить точку маршрута
- `NEW NOZZLE` — По документации · Штуцер оборудования
- `NEW DRWG /CWAY-ISO-001` — По документации · Создать чертёж
- `NEW SHEET /SH1` — По документации · Создать лист
- `NEW VIEW /V1` — По документации · Создать вид

## `POS` — Задать положение

| Аргумент | Что это |
|---|---|
| `E\|W x  N\|S y  U\|D z` | Координаты в мм. Минусы не нужны: W, S и D — отрицательные направления. |
| `WRT WORLD` | В мировых координатах. Без WRT положение отсчитывается от владельца. |
| `WRT /NAME` | От другого элемента. |
| `WRT $!!x` | От элемента, имя которого лежит в переменной. |

У примитива POS — его центр; внутри SUBE — от SUBE. У ветки лотка на POS садится манипулятор правки.

**Формы**

- `POS E 0 N 0 U 0` — Проверено · Задать положение
- `POS E 0 N 0 U 0 WRT WORLD` — Проверено · То же в мировых координатах
- `POS E 0 N 0 U 500 WRT /PMLC-CWAY-T1` — Проверено · Координаты от другого элемента
- `POS E 0 N 0 U 0 WRT $!!PMLCINS` — Проверено · От элемента, имя которого в переменной
- `POS E 8000 N 0 U 0` — Проверено · Переставить элемент

## `Q` — Спросить — напечатать, ничего не меняя

| Аргумент | Что это |
|---|---|
| `ATTR [ATTR …]` | Один или несколько атрибутов одной строкой: Q NAME TYPE OWNER. |
| `ATT · MEM · REF · POS` | Все атрибуты · члены с их =ref · устойчивая ссылка · положение (в системе владельца). |
| `ATTR OF /NAME \| =REF` | Прочитать атрибут другого элемента, не переходя к нему. |
| `POS WRT WORLD` | Положение в мировых координатах. |
| `VAR !!x` | Содержимое и тип переменной. |
| `EVAR \|NAME\|` | Переменная окружения E3D (не Windows). |

Q MEM ATT — это Q MEM плюс Q ATT ТЕКУЩЕГО элемента, а не атрибуты членов.

**Формы**

- `Q EVAR |PMLLIB|` — Проверено · Узнать путь к библиотеке PML изнутри E3D
- `Q POS WRT WORLD` — Проверено · Координаты текущего в мировых
- `Q HCREF` — Проверено · С чем соединена голова ветки (Q TCREF — хвост)
- `Q SPREF` — Проверено · Ссылка изделия на каталог (у ELCONN — Q CATREF)
- `Q DESPARAM` — Проверено · Параметры изделия из каталога
- `Q POS` — Проверено · Координаты текущего элемента
- `Q ATT` — Проверено · Все атрибуты текущего элемента
- `Q NAME` — Проверено · Имя
- `Q TYPE` — Проверено · Тип элемента
- `Q OWNER` — Проверено · Владелец
- `Q REF` — Проверено · Устойчивая ссылка вида =12345678/26685
- `Q MEM` — Проверено · Состав: что лежит внутри
- `Q DESC` — Проверено · Описание
- `Q DRAWLIST` — Проверено · Что сейчас на экране
- `Q NAME OF /PMLC-CWBRAN-T1/01` — Проверено · Прочитать атрибут БЕЗ перехода на элемент
- `Q NAME TYPE OWNER` — Проверено · Несколько атрибутов одной строкой
- `Q VAR !!x` — Проверено · Показать содержимое переменной
- `Q MEM ATT` — Проверено · Состав и атрибуты
- `Q $Q` — Проверено · Что вообще принимает команда Q
- `Q PURP` — Проверено · Признак узла (PURPOSE)
- `Q ORI` — Проверено · Ориентация

## `VAR` — Прочитать в переменную

| Аргумент | Что это |
|---|---|
| `!x \| !!x` | Локальная или глобальная. В командной строке до следующей строки доживает только глобальная !!x. |
| `ATTR` | Читает атрибут любого типа, что бы ни лежало в переменной раньше: VAR !x MAXLAY. |
| `COLLECT ALL TYPE [WITH (…)] FOR element \| WORLD` | Собирает элементы. WITH может проверять атрибут: WITH (UNSET(DESC)). По результату можно пройти циклом do … values, но .Size() у него нет. |

FOR элемент берёт всё под ним, включая вложенное.

**Формы**

- `VAR !!x ACTTYPE` — Проверено · Тип элемента проекта (:EXTZONE)
- `VAR !!x NAME` — Проверено · Прочитать атрибут текущего элемента в переменную
- `VAR !!eq COLLECT ALL EQUI WITH ( TYPE EQ 'EQUI' ) FOR CE` — Проверено · Собрать элементы с фильтром
- `VAR !!x OWNER` — Проверено · Владелец элемента в переменную — потом $!!x переходит к нему
- `VAR !x COLLECT ALL CWBRAN WITH (UNSET(DESC)) FOR /PMLC` — Проверено · Собрать с условием на атрибут
- `VAR !s COLLECT ALL SITE FOR WORLD` — Проверено · Собрать по всей базе

## `DESC` — Записать описание

| Аргумент | Что это |
|---|---|
| `\|text\| · 'text'` | Текст в вертикальных чертах или одинарных кавычках — они равноправны. Каждый $ удваивается; двойная кавычка пишется как есть; переводов строк нет. |

У примитива (BOX) DESC нет: «Current element does not have an attribute DESC». У EQUI и SUBE есть.

**Формы**

- `DESC |текст с пробелами|` — Проверено · Записать описание

## `NAME` — Переименовать текущий элемент

| Аргумент | Что это |
|---|---|
| `/NEW` | Новое имя, с косой чертой. Занятое имя отклоняется — «Name … already used» — и ничего не меняется. |

Массово: =ref, затем NAME — две строки на элемент. Чтобы поменять имена местами, — через временный префикс.

**Формы**

- `NAME /НОВОЕ` — Проверено · Переименовать ТЕКУЩИЙ элемент

## `RENAME` — То же, что NAME

| Аргумент | Что это |
|---|---|
| `/NEW` | Переименовывает текущий элемент, ровно как NAME. |

Формы с двумя именами нет: RENAME /СТАРОЕ /НОВОЕ → «(2,109) Undefined name».

**Формы**

- `RENAME /НОВОЕ` — Проверено · То же самое
- `RENAME /СТАРОЕ /НОВОЕ` — Ошибка · Так НЕ работает

## `REORDER` — Поменять порядок членов

| Аргумент | Что это |
|---|---|
| `WHAT BEFORE WHERE` | Сначала что двигаем, потом перед чем ставим. Имена целиком, со слэшем, или $!!a / $!!b с =ref безымянных. |

Меняется только порядок у владельца; координаты прежние. Форма AFTER не выполнялась.

**Формы**

- `REORDER /A BEFORE /B` — Проверено · Переставить в списке членов
- `REORDER /A AFTER /B` — Встречено в коде · То же, но после указанного

**Формы**

## `ALPHA LOG` — Писать вывод окна в файл

| Аргумент | Что это |
|---|---|
| `/PATH OVERWRITE` | Путь — одним словом, со слэшем впереди: alpha log /C:\Temp\log.txt OVERWRITE. |
| `END` | Закончить запись. |

В файл идут ответы и ошибки, сами команды — нет. UTF-8 с BOM.

**Формы**

- `alpha log /C:\Temp\log.txt OVERWRITE` — Проверено · Писать всё, что печатает окно, в файл
- `alpha log END` — Проверено · Закончить запись в файл

## `$M` — Выполнить файл макроса

| Аргумент | Что это |
|---|---|
| `PATH` | Файл макроса: $M C:\Temp\file.pmlmac. |

| `!i from a to b` | Счётчик — прогонялся from 1 to 3. |
| `!e values !list` | По списку, в том числе по результату COLLECT; $!e переходит к каждому элементу. |

Обычная вставка даёт «Invalid syntax» — нужен Paste as Macro. Остальные формы (by, while, indices) ещё не прогонялись.

**Формы**

- `do … enddo` — Только макрос · Цикл
- `do !i from 1 to 10` — Встречено в коде · Цикл по счётчику
- `do !i from 1 to 10 by 2` — По документации · Цикл с шагом
- `do !elem values !array` — Встречено в коде · Перебор значений массива
- `do !i indices !array` — Встречено в коде · Перебор индексов
- `do while ( !flag )` — По документации · Цикл по условию

## `IF` — Условие (только в макросе)

| Аргумент | Что это |
|---|---|
| `( condition ) then … endif` | Условие в скобках: if (!x GT 5) then. |

Обычная вставка даёт «Invalid syntax» — нужен Paste as Macro.

**Формы**

- `if … then … endif` — Только макрос · Условие
- `if ( !x gt 5 ) then … elseif … else … endif` — Встречено в коде · Условие, форма PML1
- `if ( !x > 5 and !n.Matchwild('PIPE*') ) then` — Встречено в коде · Условие, форма PML2

## `HANDLE` — Перехватить ошибку (только в макросе)

| Аргумент | Что это |
|---|---|
| `any … endhandle` | Сразу ПОСЛЕ строки, которую охраняет. handle any ловит переход к несуществующему элементу. |

Обычная вставка даёт «Invalid syntax» — нужен Paste as Macro.

**Формы**

- `handle any … endhandle` — Только макрос · Перехват ошибки
- `handle any … endhandle` — Встречено в коде · Перехват любой ошибки
- `handle (41,64)` — По документации · Перехват конкретной ошибки по номеру

## `!` — Переменные и объекты

| Аргумент | Что это |
|---|---|
| `!x = value · !!x = value` | Локальная (внутри макроса) или глобальная (на всю сессию). |
| `object FILE('path')` | Объект-файл: затем .ReadFile() → массив строк, .WriteFile('OVERWRITE', !строки). |
| `object ARRAY()` | Массив; .Append() добавляет. |
| `!x = ATTR` | Атрибут только в ЧИСТУЮ переменную — иначе «incompatible types»; надёжнее VAR. |

WriteFile пишет UTF-8 с BOM; ReadFile читает однобайтовую кодировку (входные файлы — в ANSI). Записываемая строка — короче 800 байт.

**Формы**

- `!!CE.Attributes()` — Проверено · Массив имён всех атрибутов текущего элемента
- `!f = object FILE('C:\Temp\out.csv')` — Проверено · Открыть файл из PML
- `!lines = !f.ReadFile()` — Проверено · Прочитать файл в массив строк
- `!f.WriteFile('OVERWRITE', !строки)` — Проверено · Записать массив строк в файл
- `!!x = 3` — Проверено · Глобальная переменная, живёт всю сессию
- `!x = 3` — Проверено · Локальная — только внутри макроса
- `!!cmd = 'Q NAME'   затем   $!!cmd` — Проверено · Выполнить команду, собранную строкой
- `!nm = NAME` — Проверено · Атрибут текущего элемента в переменную (в макросе)
- `!!a = object ARRAY()` — Проверено · Массив; .Append() добавляет
